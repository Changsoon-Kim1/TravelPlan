# TravelPlan — 2027년 4월 제주 올레길 여행 계획

지도에서 올레길 코스를 고르고, 일정(시간 구간)에 담아 캘린더로 관리하는 웹앱입니다.
**공유 링크만으로** 로그인 없이 접속합니다.

## 기능
- **지도**: Leaflet + OpenStreetMap(키 불필요). 29개 루트를 색으로 구분하고(인접 코스는 다른 색), 🌸 4월 유채·청보리 추천 코스 필터, 중문·서귀포(신라호텔 근처) 필터 제공
- **코스 상세**: 거리·예상 시간·난이도, 구경거리, 경유지, 맛집(네이버/카카오 지도 링크), 사진 검색 링크, 유용한 사이트
- **일정에 추가**: 날짜와 시간 구간(예: 10:00~15:00)을 정해 추가. 겹치는 시간은 경고
- **캘린더**: 달력/목록 보기, 수동 일정 추가·수정·개별 삭제
- **공유 링크**: 메뉴(⋯) → 공유 링크. 보기 전용 전환, 링크 끄기, 새 링크 발급 가능
- **코스 GPX 올리기**: 공식 GPX를 올리면 해당 코스가 임시 점선 → 실제 경로 실선으로 바뀜

## 지도 경로에 대해
코스 좌표는 이 저장소에 들어 있지 않습니다. 처음에는 시점·종점을 이은 **임시 대략선(점선)** 으로 표시되고,
제주올레 공식 홈페이지 등에서 받은 코스별 GPX를 앱의 `코스 GPX 올리기`로 올리면 실제 경로로 바뀝니다.
(파일 이름에 `10코스`, `7-1`, `03-A` 같은 코스 번호가 있으면 자동으로 매칭됩니다.)

## 구성
```
index.html          화면
css/style.css
js/core.js          순수 로직(색 배정, 시간 겹침, GPX 파싱/단순화) — tests/ 로 검증
js/api.js           Supabase 연동 (소유자 로그인 / 공유 링크 RPC)
js/map.js panel.js calendar.js dialogs.js app.js
data/courses.js     29개 루트 정보 (tools/build_courses.mjs 로 가이드 HTML에서 생성)
data/anchors.js     임시 대략 경로용 좌표
supabase/schema.sql 테이블 · RLS · 공유 RPC (이미 적용됨)
```

## 보안 모델
- 소유자(로그인): 테이블 RLS로 본인 데이터만 읽기/쓰기
- 공유 링크 방문자(anon): 테이블 직접 접근 불가. 토큰을 검사하는 RPC 4개(`shared_*`)만 호출 가능
- 토큰은 64자 무작위 문자열. 메뉴에서 언제든 재발급(이전 링크 즉시 무효)할 수 있음
- `js/config.js` 의 publishable 키는 공개되어도 되는 키입니다

## 지도 타일 안내
OpenStreetMap 타일은 소규모 개인 사용에 적합합니다. 공식 서버가 막히면 자동으로 대체 서버로 전환합니다.

## 장소 검색·핀
- 지도 위 검색창(OpenStreetMap Nominatim, 결과 없으면 Photon)으로 장소를 찾아 `일정에 추가` → 일정에 장소명·좌표가 저장되고 지도에 핀과 `4/14 15:00` 꼬리표가 표시됩니다. 지도를 길게 누르면 그 위치를 직접 지정할 수 있어요.
- DB: `trip_events.place/lat/lng` (supabase/schema.sql 맨 아래 마이그레이션).
- **⭐ 지도에 표시**: 검색한 장소를 날짜 없이 관심 장소로 지도에 표시(`trip_places` 테이블). 핀을 눌러 일정에 추가하거나 표시 해제.


## 코스 상세 보강
- `data/course_extra.js`: 제주올레 공식 코스 안내를 요약한 소개·구경거리·팁 (정리된 코스만, 나머지는 '보강 예정').
- 경로 모양·고도 그래프는 올린 GPX로 그립니다. 고도(ele)가 든 GPX를 다시 올리면 고도 그래프가 생깁니다.
- 공식 사진은 사이트가 SPA라 가져오지 못했습니다(라이선스 확인 전이라 앱에 넣지 않음).

## 여러 여행
- 상단 여행 이름(또는 ⋯ 메뉴 → 🧳 내 여행)에서 여행을 고르고, 새로 만들고, 이름·기간을 고치고, 삭제할 수 있어요. 마지막으로 본 여행을 기억합니다.
- 여행 종류: **🥾 올레길**(올레 코스 지도·코스 패널·올레 합계) / **🧳 일반**(장소 검색·핀·⭐·캘린더·리포트). 일반 여행은 도시 이름으로 지도 시작 위치를 정할 수 있고, 장소 검색은 전 세계에서 됩니다.
- 공유 링크는 여행마다 따로이고, 링크로 들어온 사람은 그 여행만 볼 수 있어요.
- 올레 코스 GPX 경로는 계정에 한 번만 올리면 모든 올레 여행에서 함께 씁니다.

## 사진 앨범 리포트 (album.html)
- 여행 후 하루 GPX 기록과 사진을 골라 리포트를 만드는 별도 화면입니다. 메뉴 → 📸 사진 앨범 리포트.
- **사진과 GPX는 브라우저 안에서만 처리되고 서버로 전송·저장되지 않습니다.** 결과는 PDF(인쇄) 또는 HTML 파일로 내 기기에 저장합니다.
- 사진 시각은 EXIF → GPS 시각 → 파일 이름(`20261122_141814`) → 파일 수정 시각 순으로 찾고, 위치는 사진 GPS가 있으면 그것을, 없으면 GPX 기록의 같은 시각 위치를 씁니다. 안드로이드 "사진 선택기"는 GPS를 지우는 경우가 있어 "파일"에서 고르는 것을 권합니다.
- 장면 단위 이야기 형태: 시간 20분·거리 500m 기준으로 사진을 장면으로 묶고, 장면마다 작은 지도·이동 구간·머문 시간(GPX에서 60m 안에 5분 이상 머문 곳)을 보여 줍니다.
- 배경 지도는 선택 사항입니다. 켜면 OpenStreetMap 지도 조각(타일)만 받아 한 장으로 합성하며, 사진·GPX는 전송되지 않습니다. (지도 © OpenStreetMap contributors)
